# Leonida Trophy Guide — GTA VI

An offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI (1 platinum, 2 gold, 6 silver, 46 bronze, 28 hidden), built for the [make.fun bounty](https://make.fun/bounty/gta6-trophy-guide-01).

Every guide is written in our own words in numbered steps, and every step cites its source by number — PowerPyx, OutputLog, KeenGamer, eGamers, the official list, GTA-Zone and GTA Vibes, all read 20 Nov 2026, the day after launch. 174 steps in total, all 174 cited; 55 of 55 guides cite a source.

The app shows an audit strip with the counts it computes from its own data (1 possibly missable, 1 watch, 3 unconfirmed, 5 single-source, 4 disagreements — both versions shown where sources disagree), a source matrix, a 7-stage roadmap to the platinum (~200 hours), and a tracker with saved progress, kind filters, a spoiler setting, export and import. It runs fully offline from its own files.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or serve `app/` with any static server and open `app/index.html`.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
