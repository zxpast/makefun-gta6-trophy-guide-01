Leonida Trophy Guide — an offline tracker and cited step-by-step guide for all 55 Grand Theft Auto VI trophies on PS5. Every trophy has numbered steps, each step citing one of 7 launch-day sources by number, plus a roadmap to the platinum (about 200 hours), missable and watch flags, a source matrix, and an audit strip with counts computed from the guide data itself. Progress is saved in the browser, with export and import, kind filters with counts, and a spoiler setting for hidden story trophies.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Serve `app/` with any static server (for example `python3 -m http.server` inside `app/`) and open it in a desktop browser; the guide works with the network off.
